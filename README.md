## 🚀 About Neurozy

Neurozy is a technology-driven platform focused on Artificial Intelligence, Software Development, Mobile Applications, and Digital Innovation.

Our mission is to create impactful products that help businesses and individuals leverage modern technology efficiently.

---

## ✨ Features

* Modern React + TypeScript Architecture
* Responsive & Mobile-Friendly UI
* AI-Powered Solutions & In-browser Intelligence
* Dedicated Sub-pages (Personas, SDKs, Frontline, IDN, Blog, Manifesto, Careers, etc.)
* Reusable Component System with Official Neurozy Branding
* Fast Performance with Vite

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/kumarrajjava/Neurozywebsite.git
```

Navigate to the project:

```bash
cd Neurozywebsite
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## 🔨 Build for Production

```bash
npm run build
```
